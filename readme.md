# 🏢 Simulador de Gestão Empresarial - Aprendizagem Profissional

O **Simulador de Gestão Empresarial** é uma aplicação web interativa voltada para a educação profissional. O sistema reproduz rotinas operacionais e analíticas de uma empresa, permitindo que os estudantes apliquem na prática os conhecimentos de diversas Unidades Curriculares (UCs).

---

## 🚀 Funcionalidades Principais

* **Contexto Dinâmico por Setor:** O docente pode alternar a atuação da empresa entre **Varejo**, **Indústria** e **Logística**, adaptando automaticamente a origem e o perfil dos dados.
* **Simulação de Rotina Corporativa:** Os estudantes recebem chamados, analisam bases de dados reais do ERP e tomam decisões.
* **Validação Automática e Feedback:** O sistema avalia a precisão do tratamento de dados, o cálculo de indicadores e gera notas de desempenho.
* **100% Client-Side:** Executa diretamente no navegador, sem necessidade de servidores backend ou banco de dados externo.

---

## 🏭 Matriz de Setores Atendidos

1. **Varejo / Comércio:** Vendas por filial, faturamento, ticket médio e gestão de estoque.
2. **Indústria / Manufatura:** Controle de qualidade, refugo de peças, temperatura de máquinas e tempo de ciclo.
3. **Logística / Serviços:** Consumo de combustível, rotas da frota, cumprimento de prazos (SLA) e quilometragem.
